ON VOUS RÉPOND

Les choses
en toute simplicité.

Une question avant de découvrir la suite ?

Peut-on déjà commander ? +

Ce site présente l’univers de Print et un catalogue de démonstration. Aucune commande ni aucun paiement ne sont possibles pour le moment.

Comment fonctionne la sélection ? +

Explorez les catégories et ouvrez les fiches pour découvrir les objets. Le cœur vous permet de garder vos favoris dans ce navigateur, sans créer de compte.

D’où seront expédiés les produits ? +

Le modèle envisagé est l’expédition directe par des fournisseurs partenaires. Leur identité, l’origine d’expédition et les délais devront être confirmés avant l’ouverture des ventes.

Quels seront les délais et les conditions de retour ? +

Ces informations seront publiées avec les conditions de vente avant toute prise de commande. Aucun délai de livraison ni engagement de retour n’est annoncé à ce stade.
